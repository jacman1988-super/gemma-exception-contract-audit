Task description (public commit message):
fix: only treat None and 0 as "no wait" (#741)

BaseRetrying skipped the wait strategy whenever it was falsy, so a
callable strategy that is an empty container or defines __bool__ was
never called. Match the "no wait" values (None, 0, and sum([]) over no
strategies) explicitly, and replace them with wait_none() at construction
so both the sync and async loops just call the strategy. This drops the
truthy-bool type: ignore in both _run_wait.

Supersedes #731.

    def _run_wait(self, retry_state: "RetryCallState") -> None:
        # `wait` is annotated as always set, so a type checker sees this guard
        # as always true -- but untyped callers legitimately pass `None` or `0`
        # to mean "no wait", and `sum([])` over an empty list of strategies
        # yields the int 0. Keep honouring those.
        if not self.wait:  # type: ignore[truthy-bool]
            retry_state.upcoming_sleep = 0.0
        else:
            retry_state.upcoming_sleep = self.wait(retry_state)
